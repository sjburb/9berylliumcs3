# ILA 3-1: Applying the Four Pillars of OOP

## Sari-Sari Store Inventory System

### 1. Encapsulation
Encapsulation puts a product's name, price, and stock to a single class. You can create multiple functions to edit the inventory of the store. This will keep the data organized.

### 2. Abstraction
Abstraction hides the hard processes of the program. A function like add_stock() adds stock to an item without showing the process. This makes the program easier to use.

### 3. Inheritance
Inheritance allow different products to use the same class. This avoids repeating code.

### 4. Polymorphism
Polymorphism allows different  objects to use the same method in different ways. It makes the inventory program easier to use.

## Reflection
I think encapsulation would be the most useful for the inventory system. It keeps product information together in one class. It also makes the program more organized and easier to manage.
